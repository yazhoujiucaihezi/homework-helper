开始使用

打开作业页面 → 点右下角 ⚡ → 「抓取本页题目」→「出答案」→「逐题自动填入」→ 核对后自己点提交。

第一次用要先在面板右上角 ⚙ 里填接口地址、API Key 和模型名，只存在本机。
关于"全自动安装"：浏览器不允许网页直接安装扩展或脚本，这是 Chrome 和 Edge 的安全边界。任何声称"点一下就全部自动装好"的页面，要么在骗你，要么在让你关掉安全设置。这里做到的是把链路压到最短：识别你的浏览器 → 给对正确的商店 → 装完插件后一次点击拉起篡改猴的确认页，最后那一下"安装"必须你点。
点了「一键安装脚本」，浏览器直接下载了一个文件 / 显示一堆代码？
说明篡改猴还没装好，或者装了但被禁用。回到第 1 步装好并启用扩展，再回来点一次。
如果下载了文件，把它拖到浏览器的扩展管理页（chrome://extensions）也能触发安装。
提示「无法从该网站添加应用」或商店打不开？
Chrome 应用商店在国内无法直连，这是常态。三个办法：
① 用 Edge 打开本页，Edge 加载项商店国内可直接访问；
② 给 Chrome 配代理；
③ 手动装：下载 .crx 后打开 chrome://extensions，开启「开发者模式」，把文件拖进去。
第 1 步显示"未检测到"但我明明装了？
正常。浏览器扩展默认对网页完全隐身，网页没有任何合法手段能读扩展列表。这里的检测只是尽力探测，探测不到不代表没装。只要第 2 步点下去能弹出篡改猴的安装页，就说明它是好的。
脚本装了但作业页没有 ⚡？
多半是域名不在 @match 列表里。在篡改猴管理面板点开这个脚本，在第 8 行附近加一行：
// @match *://你的域名/*
然后 Ctrl+S 保存，刷新页面。
脚本会不会偷偷上传我的数据？
不会。脚本只做三件事：读当前页面的题目文本、把你自己的 API Key 发给你填的那个 API 地址、点选项和写输入框。没有统计、没有回传、没有第三方域名。全部代码就在 .user.js 里，一百多行，可以直接翻。
