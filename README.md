# 作业抓题助手

自己用的网页答题辅助工具：抓取页面上的题目、生成答案、逐题填进去。全程不点提交。

> **这是个人自用项目。** 只为我自己的页面服务，不对外提供，也不用于任何别人的网站。
> 具体限制见文末免责声明。

## 组成

| 文件 | 用途 |
| --- | --- |
| `exam.html` | 配套演示页：内置 10 道题的测验页面，脚本只针对它开发与测试 |
| `install.html` | 单文件安装向导 + 页面绑定 |
| `index.html` | 独立的答案卡网页版（粘贴题目出答案，可复制 / 导出 CSV） |
| `作业抓题助手.user.js` | 油猴脚本本体 |

`exam.html` 和脚本是一套。脚本里的选项定位（`num_option`、`answerBg` + `aria-checked`）、
填空写入（iframe 内的 `contenteditable`）都是照着这个页面的结构做的。

## 功能

- **抓题**：一键读取整页题目，按题号切分，识别判断 / 单选 / 多选 / 填空 / 简答
- **出答案**：一次请求返回全部答案的结构化 JSON，流式渲染，题号自动对齐
- **自动填入**：逐题处理，每题停顿并滚动定位，状态栏显示进度
- **题型自适应**：以页面实际结构为准，标错题型也能纠正
- **不点提交**：全程不碰提交按钮，最后一步始终由自己完成

## 适配细节

页面结构千奇百怪，脚本对下面这些情况做了专门处理：

| 场景 | 处理方式 |
| --- | --- |
| 选项字母写在 `class="... num_option ..."` 的标签里 | 按类名定位，不依赖文本顺序 |
| 选项是「圆圈 + 文字」的自定义组件 | 从字母标签向上找选项行，点击后读 `aria-checked` / class 变化验证 |
| 选中状态落在 `aria-checked` 上 | 每次点击后比对状态快照，变了就停，避免多选被连点两次取消 |
| 作答框是 iframe 里的富文本编辑器 | 取 `contentDocument.body`，写 `innerHTML` 并派发 `input` / `keyup` |
| 多个填空共用一个 `①②③` 答案 | 按序号拆分，按页面上的先后顺序依次写入 |

识别不出来时，面板里有「**识别诊断**」，会打印它看到的容器、选项和作答框。

## 安装

1. 装 [篡改猴（Tampermonkey）](https://www.tampermonkey.net/)
2. 打开 `install.html`，按向导装脚本；或直接把 `.user.js` 拖进浏览器
3. **绑定一个页面**（见下一节）
4. 进那个页面，右下角出现 **⚡**

首次使用点面板右上角 ⚙，填接口地址、Key 和模型名，只存在本机。

## 绑定页面

脚本头部是 `*://*/*` + `file:///*`，但它**只在绑定的地址上激活**：

- **未绑定 / 未命中**：不创建任何节点、不读页面内容、不发任何请求，页面上什么都没有
- **绑定后**：只有那个地址前缀会激活，其余页面依旧完全静默

三种绑定方式：

| 方式 | 操作 |
| --- | --- |
| 安装页生成链接 | 输入地址 →「打开并绑定」→ 跳过去自动完成 |
| 篡改猴菜单 | 目标页面 → 篡改猴图标 →「⚡ 绑定当前页面」 |
| 面板设置 | 绑定后能看到当前范围，也能一键解除 |

`file://` 页面不能用链接绑定（浏览器禁止网页跳转本地文件），用篡改猴菜单即可。

解绑：目标页面 → 篡改猴菜单 →「✖ 解除绑定」，或面板设置里的「解除绑定」。

## 使用

```
打开页面 → ⚡ → 抓取本页题目 → 出答案 → 逐题自动填入 → 自己核对 → 自己点提交
```

第一次用要先绑定，见上一节。

## 接口

设置里填三项：**Base URL**、**API Key**、**模型名**。

只要接口兼容 `/chat/completions`，返回体里有 `choices[0].message.content` 就行。
填多模态模型还能识图，但配套页面不需要。

## 目录结构

```
.
├── 作业抓题助手.user.js   油猴脚本（源码，改这个）
├── install.html            安装向导 + 绑定（脚本已内联，单文件可离线用）
├── build.js                把脚本重新内联进 install.html
├── exam.html               配套演示页（10 题，自带判分）
├── index.html              答案卡网页版
├── app.js
├── styles.css
└── server.js               可选：本地静态服务 + 转发
```

改完 `.user.js` 后要跑一次 `node build.js`，否则安装页里还是旧代码。

## 本地运行

```bash
node server.js          # http://localhost:8787
# 或直接双击 index.html / install.html / exam.html
```

某些接口不允许浏览器直连，可以在设置里勾「走本地代理」，地址填 `http://localhost:8787`。

## 隐私

- Key 只写入浏览器本地存储 / 油猴存储，不经过任何第三方服务器
- 没有埋点、没有统计、没有回传
- **未绑定的页面上，脚本不读任何页面内容、不发任何请求**，只比对一次地址前缀就退出
- 全部代码都在仓库里，可以直接翻
